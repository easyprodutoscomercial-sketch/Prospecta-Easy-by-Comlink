# /mercado [feature ou tema]

Análise competitiva de **$ARGUMENTS**. Faça:

1. **Ler** `docs/MERCADO.md` primeiro (não repetir, complementar)
2. **Pesquisar** 3-6 concorrentes relevantes: como fazem, UX, preço, limitações
3. **Responder 5 perguntas:**
   - Qual é o padrão mínimo do mercado?
   - O que seria diferencial?
   - Quais armadilhas outros cometeram?
   - O que o produto atual já tem?
   - Recomendação direta (2 parágrafos com raciocínio)

## Formato
```
# 📊 Análise: <tema>

## Contexto
...

## Como os concorrentes fazem
### 1. <nome>
Fluxo | UX | Preço | Limitação

## Padrão mínimo
- [ ] ...

## Oportunidades de diferencial
1. ...

## Armadilhas a evitar
- ...

## O que o produto já tem
- ✅ / ⚠️ / ❌

## 💡 Recomendação
**Faça X.** Raciocínio...
**Esforço:** baixo/médio/alto
**Impacto:** alto/médio/baixo
```

Linguagem simples. Se nova decisão surgir, atualizar `docs/MERCADO.md`.
